Editing & saving help

Arrangement edits apply immediately. Device/effect drafts need Apply device changes. Applied edits are in memory; Save downloads a file to keep before closing.

Import PCM16/24/32 mono or stereo WAVs at the session rate, up to 32 MiB. Each import creates a new audio lane at Insert at (beat), or beat 0 in an empty session.

MIDI import: format 0/1, beat timing, up to 1 MiB. Imports notes into new lanes at project tempo; sounds, sustain, expression and source tempo maps stay outside the project. Drum channel 10 supports kick 36, snare 38 and closed hat 42.
