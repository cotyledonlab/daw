# Working on DAW

Read README.md, docs/PROTOCOL.md, and the selected ticket in docs/PLAN.md before editing. The current product has a browser GUI with live sine audition and Rust WAV export, plus optional macOS native playback through JSONL, the GUI, and CLI; schema-v2 note sequencing and preloaded PCM WAV clips are available through scripts and rate-matched native playback. Schema-v3 adds serial track gain effects, bypass, and saved step/hold gain automation. Schema-v4 adds optional macOS scripted offline VST3 effects through owned workers (`vst3-offline`); schema-v5 adds optional macOS offline AUv2 processing through an owned worker (`au-offline`), restricted to Apple AULowpass. Both plugin render paths require 48 kHz and stop at ten seconds. Optional `vst3-live` adds experimental in-process native VST3 effects through an owned DSP worker and fixed callback queue. Plugin sessions require a 48 kHz device and do not support seek/loop. The browser editor supports v1 and schema-v4 continuous sine tracks, gain chains, and controls/reuse for VST3 effects loaded from validated saved sessions; it rejects schema-v5 imports. Notes/audio clips and v2/v3 editing remain unsupported; plugin discovery/windows and AU live playback are not implemented. Keep that distinction in capabilities and user-facing documentation.

- Implement one bounded ticket per logical commit. Use `type(scope): description`, stage only the task's files, and push working states when authentication is available. Use a `codex/` branch for risky changes.
- Prefer GPT-6 Luna for bounded examples, tests, documentation, and straightforward commands. Parallelize independent files when useful. One agent owns integration and shared file edits. Native hosting, real-time concurrency, and schema design need a stronger model's review.
- Preserve versioned JSON contracts and structured errors. Validate fully before changing the active session. Never overwrite outputs implicitly. Stdout belongs to the protocol.
- Do not add speculative format stubs, generic processor traits, or unimplemented commands that claim success. Establish an interface from a second working adapter.
- No allocation, locks, filesystem/network access, subprocess startup, or foreign-code initialization in future audio callbacks. The current offline renderer is not suitable for direct callback use.
- Run `cargo fmt --check`, `cargo clippy --locked --all-targets -- -D warnings`, and `cargo test --locked`. For a client change, also run `cargo build --locked` and `python3 examples/demo.py`. Use `--offline` with an available cache when networking is unavailable.
- Keep generated audio under ignored `output/`. Do not commit recordings, temporary app state, credentials, or plugin binaries.
- For live-player changes, run `node --test gui/test_live.cjs gui/test_editor.cjs`. Browser audition is separate from native engine capabilities; do not claim browser plugin support.
- For GUI changes, run `python3 -m unittest gui.test_server` and exercise the browser against the real Rust engine. The Python bridge requires Python 3.10+ and loopback socket access. Keep HTTP file access constrained to browser uploads/downloads, preserve per-launch token/host/origin checks, and keep the Rust model authoritative.
- Update ticket status, protocol examples, and limitations with the change. Record unverified platform behavior honestly. Routine reversible implementation needs no extra approval.

- For VST3 worker/session changes, build `python3 native/vst3/build.py`, run combined `vst3-offline,native-audio` Rust checks, and run `python3 -m unittest native.vst3.test_daw native.vst3.test_metadata`. An optional `DAW_VST3_EFFECT` points to ValhallaFreqEcho for installed-plugin coverage; the owned fixture covers exact automation and child failures. Keep the native feature binary available after checks. Read-only `effect.inspect` reports metadata for saved parameter IDs; GUI structural editing requires stopped playback and never replaces saved bases with metadata's restored values. Optional live saved VST3 base edits use effect.set_parameter; reject bypassed/automated targets and preserve queue acceptance versus DSP acknowledgement semantics.

- For native-audio changes on macOS, also run `cargo clippy --locked --features native-audio --all-targets -- -D warnings` and `cargo test --locked --features native-audio`. Hardware smoke tests require host audio access; keep tones quiet and bounded. Record callback evidence separately from acoustic verification.

- For live VST3 changes, also run `cargo clippy --locked --features vst3-live --all-targets -- -D warnings`, `cargo test --locked --features vst3-live`, and `python3 -m unittest native.vst3.test_live native.vst3.test_parameters`. Explicitly run the ignored worker test with `DAW_VST3_FIXTURE_NO_EVENTS=1 DAW_VST3_FIXTURE_REALTIME=1 cargo test --locked --features vst3-live actual_live -- --ignored`. `examples/vst3_live_demo.py SESSION` is a silent hardware check; keep foreign initialization, DSP, and teardown on its owner worker. In-process hangs/crashes are not contained like offline children.

- Opt-in silent native parameter tests use `DAW_TEST_NATIVE_AUDIO=1 python3 -m unittest native.vst3.test_parameters`. Keep a single DSP owner per engine; a detached hung worker retains its lease. Reused instances share module lifetime until final teardown.

- For AU offline session changes, build `python3 native/au/build.py`, use `--features au-offline`, and run `python3 examples/au_demo.py` plus `python3 -m unittest native.au.test_daw native.au.test_probe`. Schema v5 supports only Apple AULowpass through an owned child. AUv3, other components, GUI imports/edits, and live AU remain unavailable. Keep the standalone synthetic proof distinct from acoustic and DAW callback-safety claims.

- SuperCollider NRT jobs use `supercollider.render` on Unix with explicit `DAW_SCSYNTH`. `supercollider.inspect` adds portable bounded SCgf-v2 metadata/graph inspection without claiming runtime compatibility. NRT jobs are synchronous standalone score jobs; saved runtime track devices and interactive OSC remain unimplemented. Run `python3 -m unittest native.supercollider.test_daw native.supercollider.test_inspect` and `DAW_SCSYNTH=/absolute/scsynth python3 examples/supercollider_demo.py`. Preserve score snapshots, owned process groups, bounded diagnostics/deadlines and exclusive output publication; do not claim NRT export is live runtime integration.
